# Pulse Studio — démo statique

Interface de démonstration hébergeable sur GitHub Pages, construite en HTML, CSS et JavaScript sans dépendances ni étape de compilation.

## Fonctionnalités

- Statistiques fictives : vues, abonnés, interactions et engagement.
- Boutons de simulation et génération de données aléatoires.
- Graphique décoratif et journal d'événements local.
- Aucun appel réseau, aucune API TikTok et aucune donnée réelle.

## Publier avec GitHub Pages

1. Ouvrir **Settings → Pages**.
2. Choisir **Deploy from a branch**.
3. Sélectionner `main` comme branche et `/ (root)` comme dossier.
4. Cliquer sur **Save**.

Le site est servi depuis `index.html` directement à la racine du dépôt.
